Archive the scouting phase and the abandoned datapack route; rewrite the docs to match reality

Workspace had drifted: the README described the datapack export as the deliverable, while the actual
work had moved to a Forge generator, and the tree mixed 28 MB of superseded outputs with the live
pipeline.

Layout now:

  tools/       the pipeline (unchanged)
  mod/         Forge source (FitTerrain = the model, FitParams = its JSON config)
  dist/        fit-1.0.0.jar only
  reports/     current-state.md  -- numbers, model, what did not work
  preview/     viewers/ images/ fits/  -- small, current only
  archive/     README.md + scene-identification/ reports-scouting/ datapacks/ viewers/ images/
               experiments/

Everything moved keeps its provenance; archive/README.md says what each folder is and why it is no
longer needed. Runtime-only trees (_server, _forgeserver, _mod, _map, _palette, _tpl) are gitignored.
